# ULSAN HD FC 1 VS 1 축구

울산 HD FC 선수 12명 중 하나를 골라 60초 헤드 사커 1대1 경기를 하는 팬 미니게임입니다.
선수마다 필살기가 하나씩 있고, 공을 건드려 게이지가 차면 터집니다. 컴퓨터와 하는 1인 대전(난이도 5단계), 한 키보드로 하는 2인 대전, 초대 링크로 친구와 하는 온라인 대전이 있습니다. 유니폼은 2026 시즌 4종과 레트로 줄무늬 중에서 고르고, 골키퍼 조현우는 GK 유니폼 4종 중에서 고릅니다.

플레이: https://robinkim0221.github.io/ulsan-head-soccer/

폰은 가로로 돌려서 플레이합니다.

## 조작

| | 폰 | 키보드 |
|---|---|---|
| 이동 | 왼쪽 ◀ ▶ | ← → |
| 점프·헤딩 | 점프 | ↑ |
| 슛 | 슛 | Space |
| 필살기 | 게이지가 다 차면 자동 | 자동 |
| 교체 | 위쪽 교체 버튼 | 위쪽 교체 버튼 |
| 일시정지 | 위쪽 메뉴 버튼 | Esc |

슛 필살기(레이저 슛·감아차기)는 게이지가 찬 뒤 슛을 누르거나 공이 몸에 맞으면 나갑니다. 기다리는 동안 선수 발밑에 금색 고리가 켜집니다.

**2인 대전**: 한 키보드를 둘이 나눠 씁니다. 왼쪽 선수는 A·D 이동, W 점프, Tab 슛. 오른쪽 선수는 ← → 이동, ↑ 점프, Space 슛.

**온라인 대전**: 선수 선택 화면에서 **온라인**을 누르면 방이 만들어지고, 초대 링크를 친구에게 보내면 같은 방에 들어옵니다. 둘 다 선수를 고르고 **준비**를 누르면 시작합니다. 방은 두 명까지이고, 모르는 사람과 자동으로 붙는 기능은 없습니다.

## 소리

효과음은 파일 없이 Web Audio 로 합성합니다. 첫 터치나 키 입력 뒤부터 소리가 나고, 선택 화면이나 일시정지 메뉴의 "♪ 소리" 버튼으로 끌 수 있습니다.

python -m http.server 8766
