# ULSAN HD FC 일대일축구

울산 HD FC 선수 12명 중 하나를 골라 컴퓨터 상대와 90초 헤드 사커 1대1 경기를 하는 팬 미니게임.
선수마다 필살기가 하나씩 있고, 공을 건드려 게이지를 채운 뒤 쓴다. 경기 중 한 번 선수 교체가 가능하다.

플레이: https://robinkim0221.github.io/ulsan-head-soccer/

폰은 가로로 돌려서 플레이한다. 세로 화면이어도 게임은 가로로 그려지므로(인스타 인앱 브라우저 포함) 폰만 돌리면 된다.

## 조작

| | 폰 | 키보드 |
|---|---|---|
| 이동 | 왼쪽 ◀ ▶ | ← → (A D) |
| 점프 | 점프 | ↑ 또는 Space (W) |
| 킥 | 킥 | Z 또는 K |
| 필살기 | 필살기 (게이지가 다 차면 노란 링) | X 또는 L |
| 교체 | 위쪽 교체 버튼 | C |

## 선수와 필살기

| 번호 | 선수 | 필살기 |
|---|---|---|
| 10 | 이동경 | 레이저 슛 — 다음 킥이 직선으로 상대를 뚫고 날아간다 (가까이서 쏴야 들어간다) |
| 11 | 에릭 | 스프린트 — 두 배로 빨라지고 킥이 세진다 |
| 14 | 이진현 | 커브 슛 — 다음 킥이 상대 머리 위로 넘어가 골문으로 휜다 |
| 15 | 정승현 | 높이뛰기 — 더 높이 뛰고 헤딩이 두 배 |
| 19 | 김영권 | 거인 수비 — 몸이 커져 골문을 막는다 |
| 21 | 조현우 | 선방 캐치 — 머리 위로 오는 공을 잡아 멀리 던진다 |
| 24 | 이규성 | 공 자석 — 가까운 공이 발 앞으로 끌려온다 |
| 26 | 조현택 | 롱스로인 — 공을 집어 상대 골문 앞으로 던진다 |
| 38 | 박용우 | 압박 — 상대가 느려지고 낮게 뛴다 |
| 55 | 토마스 | 기관차 모드 — 기차가 되어 공과 상대를 골문으로 밀어 넣는다 |
| 96 | 최석현 | 슬라이딩 — 미끄러지며 공을 걷어내고 상대를 넘어뜨린다 |
| 99 | 야고 | 대포 헤딩 — 헤딩이 두 배, 맞은 상대는 밀려난다 |

## 로컬 실행

```
python -m http.server 8766
# http://127.0.0.1:8766/
npm test                   # 규칙·물리·AI 테스트 (node --test)
npm run selfplay -- 60     # AI 끼리 승률표 → docs/balance-날짜.md
node tools/shots.cjs       # 화면·입력 검사 (Playwright, 서버 띄운 뒤)
```

`?debug=1` 을 붙이면 선택 화면 없이 이동경 vs 야고로 바로 시작한다 (`&home=55&special=1` 식으로 선수·게이지 지정).

## 알려진 점

- AI 끼리 돌린 승률표(`docs/balance-2026-10-31.md`)에서 정승현(높이뛰기)과 이규성(공 자석)은 35% 아래다. 수비형 버프를 AI 가 살리지 못해서이고, 사람이 쓰면 그대로 쓸모가 있어 더 깎지 않았다.
- 소리와 온라인 대전은 아직 없다.

## 구조

- `js/sim/` 물리·경기 규칙·필살기·AI (DOM 없음, 테스트와 셀프 플레이가 그대로 씀)
- `js/render/` 캔버스 그리기, `js/ui/` 입력·회전·화면 흐름, `js/main.js` 부팅
- `docs/superpowers/` 설계서와 실행 계획
