# ULSAN HD FC 일대일축구

울산 HD FC 선수 12명 중 하나를 골라 컴퓨터 상대와 90초 헤드 사커 1대1 경기를 하는 팬 미니게임.
선수마다 필살기가 하나씩 있고, 공을 건드려 게이지를 채운 뒤 쓴다. 경기 중 한 번 선수 교체가 가능하다.

플레이: (배포 후 주소 기입)

폰은 가로로 돌려서 플레이한다. 세로 화면이어도 게임은 가로로 그려진다.

## 로컬 실행

```
python -m http.server 8766
# http://127.0.0.1:8766/
npm test          # 규칙·물리 테스트
npm run selfplay  # AI 끼리 승률표
```

선수 사진 출처: 울산 HD FC 공식 홈페이지 (uhdfc.com)
