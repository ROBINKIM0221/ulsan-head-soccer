# ULSAN HD FC 1 VS 1 축구

울산 HD FC 선수 12명 중 하나를 골라 컴퓨터 상대와 60초 헤드 사커 1대1 경기를 하는 팬 미니게임.
선수마다 필살기가 하나씩 있고, 공을 건드려 게이지가 차면 자동으로 터진다. 경기 중 한 번 선수 교체가 가능하다. 난이도는 5단계. 유니폼은 2026 시즌 4종(홈·어웨이·서드·포스)과 울산 호랑이 시절 줄무늬 레트로 중 고르고, 골키퍼 조현우는 GK 유니폼 4종(2026·2025 홈·원정) 중 고른다. 상대 유니폼은 내 것과 다른 계열(진한 파랑 계열 홈·서드·레트로 ↔ 밝은 계열 어웨이·포스) 중 경기마다 무작위. 선택 화면은 왼쪽 반이 나, 오른쪽 반이 상대다: 1인이면 컴퓨터(기본은 물음표 "랜덤 상대" 카드, 얼굴을 누르면 지정 — 지정한 상대는 저장하지 않아 다시 열면 늘 랜덤 상대)와 난이도, 2인이면 2P 선수와 유니폼. 승패가 갈리면 이긴 쪽 벤치 선수들이 우르르 달려 나와 경기장 가득 퍼져 세레모니를 한다(져도 상대 팀이 하지만, 그땐 색종이 없이 LOSE 글자와 아쉬운 노래).

플레이: https://robinkim0221.github.io/ulsan-head-soccer/

폰은 가로로 돌려서 플레이한다. 세로 화면이어도 게임은 가로로 그려지므로(인스타 인앱 브라우저 포함) 폰만 돌리면 된다.

## 조작

| | 폰 | 키보드 |
|---|---|---|
| 이동 | 왼쪽 ◀ ▶ | ← → (A D) |
| 점프·헤딩 | 점프 | ↑ 또는 Space (W) |
| 슛 | 슛 | Space |

**2인 대전**(선택 화면 가운데 "1인 | 2인"): 오른쪽 반이 2P 선수 카드가 되고(유니폼 5벌·GK 4벌 전부 고를 수 있다), 한 키보드를 반씩 나눠 두 사람이 붙는다. 선택 화면에서도 1P 는 A·D, 2P 는 ← → 로 선수를 넘긴다. 왼쪽 선수는 A·D 이동, W 점프, Tab 슛. 오른쪽 선수는 ← → 이동, ↑ 점프, Space 슛. 컴퓨터·난이도·교체는 없고, 누가 이겨도 VAMOS! 세레모니.
| 필살기 | 자동 (이름 아래 게이지가 다 차면 터진다) | 자동 |
| 교체 | 위쪽 교체 버튼 | 위쪽 교체 버튼 |
| 일시정지 · 메인으로 | 위쪽 메뉴 버튼 | Esc |

마우스가 있는 기기(노트북)에서는 화면 아래 가운데에 작은 키캡 안내(방향키·Space)가 보인다. 경기장은 화면 폭에 맞춰 그려진다: 화면이 16:9 보다 옆으로 길면(노트북 창·폰) 하늘 위쪽과 잔디 아래쪽이 조금 잘리는 대신 선수와 공이 커지고, 높이 뜬 공이 화면 위로 나가면 금색 화살표가 위치를 알려 준다. 16:9 보다 세로로 길면(태블릿) 위아래 여백에 경기장 그림이 이어진다. 필살기가 터지면 그 선수 얼굴과 필살기 이름이 옆에서 컷인으로 들어온다. 세레모니의 점프와 (이겼을 때의) 색종이는 폰의 "애니메이션 제거(움직임 줄이기)" 설정과 상관없이 나온다.

## 소리

효과음은 파일 없이 Web Audio 로 합성한다(킥·헤딩·골·필살기·휘슬·세레모니 함성 등, `js/sound.js`; 심판 호루라기는 콩알 떨림과 바람 소리에 경기장 울림까지 합성). 첫 터치나 키 입력 뒤부터 소리가 나고, 선택 화면 가운데나 일시정지 메뉴의 "♪ 소리" 버튼으로 끄면 기억된다.

## 로컬 실행

```
python -m http.server 8766
# http://127.0.0.1:8766/
npm test                   # 규칙·물리·AI 테스트 (node --test)
npm run selfplay -- 60     # AI 끼리 승률표 → docs/balance-날짜.md
node tools/shots.cjs       # 화면·입력 검사 (Playwright, 서버 띄운 뒤)
node tools/faces.cjs       # 바탕화면 선수 배너 → img/N.jpg(선택 화면) + img/Nc.png(경기 컷아웃), 얼굴 자동 검출
```

`?debug=1` 을 붙이면 선택 화면 없이 이동경 vs 야고로 바로 시작한다 (`&home=55&special=1&kit=third` 식으로 선수·게이지·유니폼 지정, 유니폼 id 는 `js/data/kits.js`).

## 알려진 점

- AI 끼리 돌린 승률표(`docs/balance-2026-11-13.md`)에서 35–65% 밖은 토마스 69%, 정승현 21%, 이규성 24%. 정승현·이규성은 수비형 버프를 AI 가 살리지 못해서이고, 사람이 쓰면 그대로 쓸모가 있어 더 깎지 않았다.
- 배경음악과 온라인 대전은 아직 없다.

## 구조

- `js/sim/` 물리·경기 규칙·필살기·AI (DOM 없음, 테스트와 셀프 플레이가 그대로 씀)
- `js/render/` 캔버스 그리기(`stadium.js` 경기장, `scene.js` 한 프레임·HUD·연출, `characters.js` 선수·공, `party.js` 세레모니), `js/ui/` 입력·회전과 화면 맞춤(`orientation.js`)·화면 흐름(`screens.js`), `js/main.js` 부팅
- `fonts/` 숫자 글꼴 Teko(SIL OFL, 라이선스 동봉), `img/og.jpg` 링크 미리보기, `img/favicon-32.png`·`icon-192.png`·`apple-touch-icon.png` 아이콘
- `docs/superpowers/` 설계서와 실행 계획
